# Excel Data Analysis Project

## Tools Used
MS Excel, Pivot Table, Charts

## Project Overview
Analyzed sales data to find city-wise and product-wise performance using Pivot Tables.

## Key Questions Solved:
1. Which city had the highest total sales? → Pune with ₹52,500
2. Which product generated maximum revenue? → Laptop
3. How many orders came from each city? → Nagpur: 3, Pune: 2, Mumbai: 1

## Skills Demonstrated:
- Data Cleaning
- Pivot Tables: Sum, Count, Average
- Data Summarization & Insights
